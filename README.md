# أذكار الصباح - Morning Adhkar Application

تطبيق تفاعلي لأذكار الصباح كاملة من حصن المسلم، مزود بتلاوات صوتية نقية لكل ذكر، عداد إلكتروني لمتابعة التكرار، ومشغل صوتي متتالي (تشغيل الكل) للاستماع اليومي.

## المميزات (Features)

- 📿 **أذكار الصباح كاملة**: 31 ذكراً ودعاءً من حصن المسلم مع بيان الفضل والمصدر القرآني/الحديثي.
- 🔊 **مشغل صوتي مدمج**: تلاوات صوتية نقية (Hamad Al-Duraihem & Mishary Alafasy) مع شريط تقدم وتحكم في السرعة.
- 🔄 **تشغيل متتالي (Play All)**: استماع متتالي لجميع الأذكار تلقائياً مع تمرير سلس ومتابعة الإنجاز.
- ⚡ **تكرار مع العد الآلي**: زيادة العداد تلقائياً مع انتهاء التلاوة وتكرارها حسب العدد المطلوب.
- 📱 **واجهة عصرية متجاوبة**: خط أميري عربي أصيل وتصميم مريح للعين.

## التشغيل محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
